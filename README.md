# 小小夢魔：星幣迷夢

原創靜態網頁理財遊戲，適合小學生。以兩個互動關卡練習生活預算與分散投資風險；遊戲不涉及真實金錢，也不提供投資建議。

## 遊玩

開啟網站首頁即可遊玩。第一關安排 30 枚星幣，第二關在三種夢境園圃之間分散 20 枚星幣。每關解題可取得 KEY，結尾顯示每關得分與解題足跡。

## 部署

GitHub Pages 由 .github/workflows/deploy-pages.yml 自動部署。將儲存庫 Pages Source 設為 **GitHub Actions**；之後推送至 main 即會重新發布。

## 素材

關卡背景為 assets/level1.svg 和 assets/level2.svg 原創向量插畫。網站不需伺服器、第三方 API 或外部遊戲引擎。
